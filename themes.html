How to install a theme

  1. Download the .overgrowpack file.
  2. Double-click it — OverGrow imports the world and opens Settings → World.
  3. Pick the new world from the list and let it grow.

Submit your world

Made something with the Theme Studio? Open a pull request to the theme repo and it shows up in this gallery automatically. If it gets picked, you get permanent credit plus a free copy of OverGrow.
